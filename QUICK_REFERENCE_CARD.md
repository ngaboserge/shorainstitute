# 🎯 Quick Reference Card - Course Assignment

## 📍 Where to Assign Courses

```
Login → Programmes → Right Sidebar → "Assign Programme" Button
```

**URL**: `http://localhost:3000/institutional/programmes`

---

## 🚀 5-Second Guide

```
1. Click "Assign Programme"
2. Select course
3. Choose "By Email"
4. Enter emails
5. Click "Assign"
```

---

## 📊 Status Badges

| Badge | Meaning | Result |
|-------|---------|--------|
| 🟢 **✓ Has Account** | Employee exists | Immediate assignment |
| 🟠 **ⓘ Will Send Invitation** | Employee new | Invitation sent |

---

## 💰 Course Types

| Type | Action | Payment |
|------|--------|---------|
| **FREE** | Assign anytime | No payment |
| **PAID** (Testing) | Assign now | Payment disabled |

---

## 🎯 Assignment Methods

1. **By Email** ⭐ - Best for any situation
2. **All Employees** - Company-wide training
3. **Specific Department** - Department training
4. **Specific Cohort** - Group training
5. **Select Individuals** - Pick specific people

---

## ✅ Quick Checklist

**Before Assigning:**
- [ ] Migration ran successfully
- [ ] Logged in as institutional admin
- [ ] Course selected
- [ ] Start date set

**After Assigning:**
- [ ] Success message appeared
- [ ] Employees can see course
- [ ] Notifications sent (if enabled)

---

## 🐛 Quick Fixes

| Problem | Solution |
|---------|----------|
| Button not visible | Refresh page, check sidebar |
| No courses | Need published courses first |
| Email check slow | Wait a moment, check network |
| Course not showing | Refresh employee dashboard |
