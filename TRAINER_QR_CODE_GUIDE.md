# Trainer's Guide: Using QR Codes for Seminar Registration

## 🎯 What This Does

Generate a QR code that people can scan to **instantly see your seminar and register** - no browsing through lists, no confusion, just a direct path from QR code to registration.

---

## 📋 Quick Start Guide

### Step 1: Access Your Seminars
1. Log in to your trainer portal
2. Go to **"Manage Seminars"** from the sidebar
3. Find the seminar you want to promote

### Step 2: Generate QR Code
1. Click the **"QR Code"** button on your seminar card
2. A modal will open showing:
   - Preview of your QR code
   - The landing page URL
   - Instructions

### Step 3: Download
1. Click **"Download QR Code"** button
2. A PNG file will download to your computer
3. The file will be named: `seminar-qr-[id].png`
4. Image size: **800x800 pixels** (perfect for printing)

### Step 4: Use It!
**Print it on:**
- Event posters
- Flyers
- Table tents
- Roll-up banners
- Business cards
- Certificates

**Share digitally:**
- Social media posts
- Email campaigns
- WhatsApp groups
- Website banners
- Presentation slides

## 💡 Pro Tips

### Design Tips
- **Print Size**: The QR code is 800x800px - perfect for posters up to A3 size
- **Placement**: Put it where people can easily scan it (not too high/low)
- **Call to Action**: Add text like:
  - "Scan to Register"
  - "Register Now - Scan Here"
  - "Free Seminar - Scan to Join"

### Marketing Tips
- **Test First**: Scan your own QR code to test the flow
- **Make it Obvious**: Use a contrasting background
- **Add Context**: Show seminar title near the QR code
- **Track Results**: Check registrations to see QR code effectiveness

### Best Practices
- ✅ Generate a fresh QR code if you update seminar details
- ✅ Test the QR code before printing in bulk
- ✅ Include the URL below the QR code as backup
- ✅ Use high-quality paper for printed materials
- ✅ Ensure good lighting where QR code is displayed

## ❓ Common Questions

**Q: Can I generate multiple QR codes for the same seminar?**  
A: Yes! You can generate it as many times as you need. Each generates the same URL.

**Q: What if I update my seminar details?**  
A: The QR code URL stays the same, and the landing page will show updated details automatically.

**Q: Can people register without scanning the QR code?**  
A: Yes! They can also:
- Browse seminars in the portal
- Search for your seminar
- Use the direct URL

**Q: What happens if the seminar is full?**  
A: The "Register" button will show "Full" and be disabled.

**Q: Can I customize the QR code color?**  
A: Currently it uses SHORA brand blue (#0B4F9F). Customization coming soon!

**Q: Does it work on all phones?**  
A: Yes! Modern phones have QR scanners built into the camera app.

## 🆘 Troubleshooting

**QR code won't scan:**
- Ensure good lighting
- Hold phone steady
- Try different QR scanner app
- Check if QR code is clear (not blurry/damaged)

**Landing page not loading:**
- Check internet connection
- Verify seminar is published (not draft)
- Contact support if issue persists

**Registration not working:**
- Ensure seminar hasn't reached capacity
- Check if registration deadline passed
- Verify user has internet connection
