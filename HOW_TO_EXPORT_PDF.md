# How to Export Registration PDF Reports

## Quick Guide (30 seconds)

1. **Log in** as trainer
2. Go to **"Manage Seminars"**
3. Click **"Registrations"** button on any seminar
4. Click **"Export PDF"** button (blue button with document icon)
5. PDF downloads automatically to your Downloads folder

That's it! 🎉

## Step-by-Step Instructions

### Step 1: Navigate to Registrations
1. From the trainer dashboard sidebar, click **"Manage Seminars"**
2. Find the seminar you want to export
3. Click the **"Registrations"** button (Users icon)

### Step 2: Review the Data
- Check the registration count
- Review learner details
- Use filters if needed (status, search)
- Make sure you're seeing the data you want to export

### Step 3: Export to PDF
1. Look at the top right of the page
2. You'll see two export buttons:
   - **"Export CSV"** (gray button)
   - **"Export PDF"** (blue button with FileText icon)
3. Click **"Export PDF"**

### Step 4: Wait for Download
- PDF generation takes 1-3 seconds
- Your browser will automatically download the file
- Look in your **Downloads** folder

### Step 5: Open and Review
1. Locate the downloaded PDF file
   - Filename format: `{seminar_name}_registrations_{date}.pdf`
   - Example: `shora_institute_hybrid_seminar_registrations_2026-07-24.pdf`
2. Open with any PDF reader (Adobe, Chrome, Edge, etc.)
3. Review the professional report

## Tips & Tricks

### Best Practices
1. **Export regularly**: Keep records as seminars progress
2. **Check filters**: Make sure filters are set correctly before export
3. **File naming**: Files are automatically named with date for easy organization
4. **Multiple exports**: You can export both CSV and PDF - they complement each other

### Troubleshooting

**Problem**: "Export PDF" button is gray/disabled
- **Solution**: No registrations found. Check your filters or wait for learners to register.

**Problem**: PDF doesn't download
- **Solution**: Check browser pop-up blocker settings. Allow downloads from your site.

**Problem**: PDF looks different than expected
- **Solution**: Make sure you have the latest updates. Try refreshing the page.

**Problem**: Missing custom question answers
- **Solution**: This was a known issue that has been fixed. The answer IDs have been migrated.

**Problem**: Can't open the PDF
- **Solution**: Use a PDF reader like Adobe Acrobat, Chrome, or Edge. All modern browsers support PDFs.

## Advanced Usage

### Filtering Before Export
You can filter registrations before exporting:

1. **Search by name/email**: Use the search box
2. **Filter by status**: Use the status dropdown
   - All Status
   - Registered
   - Attended
   - Cancelled
   - No Show

The export will **only include filtered results**, so you can create custom reports!

### Example Use Cases

#### Export Only Attended Learners
1. Set status filter to "Attended"
2. Click "Export PDF"
3. Result: PDF with only learners who attended

#### Export Specific Learners
1. Search for learner name
2. Click "Export PDF"
3. Result: PDF with only matching learners

#### Export Cancelled Registrations
1. Set status filter to "Cancelled"
2. Click "Export PDF"
3. Result: PDF showing who cancelled
