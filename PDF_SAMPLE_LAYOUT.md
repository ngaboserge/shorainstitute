## Color Scheme

### Header
- **Background**: Dark Blue (#0B4F9F)
- **Text**: White (#FFFFFF)
- **Font**: Helvetica Bold, 24pt (title), 16pt (subtitle)

### Info Box
- **Background**: Light Blue (#E3F2FD)
- **Border**: Rounded corners (3px radius)
- **Title**: Dark Blue (#0B4F9F), Bold, 14pt
- **Details**: Gray (#666666), Normal, 10pt

### Table
- **Header**: Dark Blue background, White text, Bold, 9pt
- **Body**: Black text (#333333), 8pt
- **Alternating Rows**: White / Light Gray (#F5F7FA)
- **Borders**: Grid style with gray lines

### Footer
- **Text**: Gray (#666666), 8pt
- **Position**: Centered at bottom

**File Size**: ~50-100 KB (depending on number of registrations)

**Format**: PDF (Portable Document Format)

**Pages**: Auto-calculated based on number of registrations
- Approximately 20-30 registrations per page
- Automatic page breaks
- Footer on every page

## Comparison: CSV vs PDF

### CSV Export
- Spreadsheet format
- Great for data analysis
- Can open in Excel
- Plain text, no formatting

### PDF Export ⭐
- Professional report format
- Branded design
- Ready to print/share
- Includes all context
- Perfect for presentations

## When to Use PDF

1. **Presenting to stakeholders**: Show professional reports
2. **Printing for events**: Have physical copies at seminar
3. **Email to co-trainers**: Share comprehensive overview
4. **Archive records**: Save for future reference
5. **Board meetings**: Include in meeting materials

## When to Use CSV

1. **Data analysis**: Import into spreadsheet
2. **Mail merges**: Send personalized emails
3. **Backup**: Machine-readable format
4. **Integration**: Feed into other systems
